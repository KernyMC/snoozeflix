# Feature Spec: ShamePool — get charged when you flake on your goals

## Summary
Friends form a **squad**. Each member commits to goals with a location, schedule and penalty. Check-ins are verified by GPS (time inside a radius) + a photo checked by AI. Missed deadlines trigger an automatic, escalating charge into the squad's **pool**. A live leaderboard, a feed and **Squad Bot** (an AI agent, also in the squad's Relay group chat) make every flake public. The pool has a goal ("Pizza night — $60") and gets spent together.

## Glossary
- **Squad**: one group (one per user in MVP). **Pool**: shared money bucket. **Goal**: a recurring commitment. **Check-in**: one attempt for a goal on a local date. **Flake**: deadline passed without a completed check-in. **Penalty**: charge generated by a flake. **Flakey**: mascot. **Squad Bot**: AI agent.

## User stories

### US1 — Onboard and join a squad (P1)
Enter a name + pick an emoji avatar, then create a squad (name, pool goal name, pool goal amount) or join with a 6-char invite code. Demo mode: "Who are you?" screen lets a device claim a seeded user.
**Acceptance:** new user starts with $200.00 balance; creating a squad shows its invite code with Copy/Share.

### US2 — Create a commitment (P1)
Fields: title, location (map pin or "Use my location"), radius (100 m default, 150 m demo), days of week, deadline time, minimum stay (30 min; 1 min demo), base penalty ($5), escalation (doubles per consecutive flake, cap $40). Live preview: "Miss it twice in a row → $10".
**Acceptance:** goal appears on Home and as a "commit" event in the squad feed.

### US3 — Check in with GPS + photo (P1)
Start → location check (distance if outside) → stay timer (re-check every 30 s) → photo → AI verdict.
**Acceptance:** outside radius shows "You're 1.2 km from Gym"; leaving early fails; couch photo rejected with a roast; success adds streak 🔥 + confetti. Demo "Pretend I'm there" toggle.

### US4 — Automatic penalty on flake (P1) 💸
Deadline passes without completed check-in: penalty = `min(base × 2^consecutiveFlakes, cap)`, moved from member balance to pool, streak reset, feed event + bot roast. One penalty per goal per date. Demo **Flake now**.
**Acceptance:** after Flake now, every open screen shows new pool, leaderboard order and roast within ~2 s.

### US5 — Squad dashboard (P1)
Pool card (balance, goal, progress, funders), leaderboard (completion % this week, streak, total paid, "Flake of the Week 🥶"), live feed, message box. Projector layout at `/squad?tv=1`.

### US6 — Squad Bot (P1)
- In-app: `@squadbot` questions and actions ("raise my gym penalty to $10" → confirm → done).
- Proactive: roasts flakes, hypes streaks 3/5/10, announces pool 50%/100%.
- Live: same bot in the squad's Relay chat (Phase B).

### US7 — Spend the pool (P2)
Pool ≥ goal → propose cash-out → members vote → strict majority → pool spent at "Pizza House" → celebration → set new goal.

### US8 — Voice roast (P3, Phase B, if time)

## Edge cases (authoritative list in `edge-cases.md`)
Every story must satisfy the matching rows in `edge-cases.md`. Highlights: insufficient balance, double-flake idempotency, GPS denied, camera denied, stale check-ins, timezone/DST, deleted goal mid-check-in, cash-out vote ties, empty squad.

## Non-goals
Real money, real backend auth (mock login, register and password reset exist; see auth-plan.md), background GPS, multiple squads per user, native apps, appeals, push notifications.

## Demo script (2 min)
1. Hook: "Resolutions fail because breaking them is free. We made it cost you — and your friends are watching."
2. Projector: `shamepool.tech/squad?tv=1` — pool "$35 / $60 Pizza night", leaderboard, feed.
3. Teammate checks in at "the gym" → gym photo → ✅ → projector updates, bot hypes the streak.
4. Kevin tries a couch photo → ❌ AI roast.
5. **Flake now** → $10 (2nd flake, doubled) → pool jumps, Kevin "Flake of the Week 🥶", bot roasts him.
6. "@squadbot how close are we to pizza?" → "$45 of $60. Kevin's carrying the team financially 💀".
7. Close: "Not gambling — nobody profits from your failure; your friends just eat pizza on it."
